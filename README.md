# 待办本子

一本会自己翻页的日程本。零依赖 PWA，装到 iPhone 主屏幕上用。

- **怎么装到手机上** → 看 `部署说明.md`
- **本地预览** → 双击 `start.bat`

## 功能

### 📓 本子

- 每天一页，7 个固定时间块（6:30–23:30）
- 打开 / 回到前台 / 跨过午夜，**自动翻到新的一页**（三层保险）
- 一天一色，**16 套配色**（11 浅色 + 5 饱和色），默认薄荷浅绿
- 字号三档：**标准 19px / 大 22px / 特大 25px**（iOS 备忘录正文 17pt）
- **全站没有小于 15px 的字**

### ✅ 待办

- 点右下角 **⊕** 直接开一条，光标自动到位，打完字停 0.45 秒自动存
- 点圆圈打勾；**清空文字 = 删除**（点进那一行还会出现 ×）
- 输入框**自动长高**：短的占一行，长的自己换行
- **每条待办可以单独左划 → 只专注这一条**（专注面板标题就是这条待办）

### 🎯 专注（左划进入）

| 操作 | 说明 |
|---|---|
| **左划整页** | 进专注，默认算在当前时间块上 |
| **左划某条待办** | 进专注，只算这一条 |
| **长按圆环 1.5 秒** | 开始计时 |
| **长按圆环 15 秒** | 结束退出（中途松手归零重来） |
| **左上角 ✕ / 右划** | 还没开始时可以随时退出；**开始之后这两个都没了** |
| **🌙 熄灯** | 整页变纯黑，OLED 屏真省电 |

#### 专注的账是怎么记的

```
你开始专注
     ↓
计时一直走 —— 息屏、切去查题、回微信，都不打断你
     ↓
结束时给你两个数，不藏：
    总时长      4h05m
    离开        3 次，共 21m
    ───────────────────
    有效专注    3h44m        92%
     ▓▓▓▓▓▓▓▓▓░░▓▓▓▓▓▓▓▓▓▓▓▓   ← 专注时间线
```

- **计时靠时间戳**，不靠定时器累加。息屏、切后台、页面被 iOS 回收，时长都不会错。
- **短离开（< 2 分钟）不扣** —— 查题、上厕所算正常范围。超过就扣。
- **页面被杀掉**后重开自动接着算；中间那段无从得知的，诚实标成「不明」。
- **严格模式**：一离开就作废整个会话（设置里可切）。

底部那条「今日有效专注 xx / 12h」读的就是这个真实数字，
**不是按待办勾选折算的估计值**。

> 12h 怎么来的：英语 1h + 上午 4h + 下午 4h + 晚间 3h = 12h，正好是你那四个学习块。

### 📊 日总结（右划进入）

- **环形图**：12h 目标是那个圈，已完成的弧按时间块切成段，一眼看出时间花在哪
- **日程**：每块的 计划 vs 实际专注 + 待办完成情况
- **习惯**：英语 / 背单词 / 运动 / 练字，点一下打卡
- **睡眠**：🌙 我睡了 / ☀️ 我醒了，两个都点了会算睡眠时长和 7h 目标差距
- **全天时间线**：所有专注会话合并后铺在 6:30–23:30 上，今天还标了「现在」

### 📅 周历（底部第一个本子）

**一周一行，点开就是一条可以一路往下滑的时间线。**

```
┌─────────────────────────────────┐
│ 小本子                      ✕   │
│ [周历] [习惯] [备份]             │
│ [待办完成] [专注时长]            │
│      一  二  三  四  五  六  日  │  ← 钉住的表头
│ 9/21  21 22 23 24 25 26 27      │  ← 本周（最新）
│ 9/14  14 15 16 17 18 19 20      │
│ 9/7    7  8  9 10 11 12 13      │
│ 8/31  ...                       │
│ ...            ↓ 一直往下滑      │
│ 1/5    5  6  7  8  9 10 11      │  ← 你记录的第一周
└─────────────────────────────────┘
```

- **最新的在最上面**，往下滑就是往回看
- 左边一列是这一周的日期范围
- 每个格子里：日期号 + 完成度圆环 + 完成数；有照片的挂个 📷 角标
- 圆环两种读数：**待办完成比例** / **有效专注 ÷ 12h**
- 点任意一天跳过去
- **滑到底会继续加载**（一次画 14 周，不是把 52 周一口气画完，不然手机要卡）

### 📊 习惯（第二个标签页）

行 = 习惯，列 = 周，越往右越近：

```
习惯    8/04 8/11 8/18 ... 9/15
英语    7/7  6/7  7/7  ...  6/7
运动    5/7  4/7  6/7  ...  6/7
练字    7/7  7/7  6/7  ...  7/7
背单词  6/7  5/7  7/7  ...  7/7
```

- 格子里是「**这周完成几天 / 这周已过几天**」（未来的日子不算进分母）
- 满格的那一周是实色，一眼看出哪几周断了
- 最下面一行是每个习惯**总共坚持了多少天**和**当前连续多少天**
- 表默认滚到最右边（最近这几周）

### ✍️ 日记本（往下划到底）

- 左上角是日期，右上角小加号加照片
- 照片自动压缩：长边压到 1280、JPEG 0.72（原图 3–5MB → 约 170KB）
- 点小图看大图，大图界面能删
- 列表只解码缩略图，攒几百张也不卡

> **为什么必须压**：iPhone 原图一张 3–5MB，不压的话每天 15 张、一年 7GB。
> 压完每天 15 张、一年约 930MB —— 你那 3GB 够用三年。

### 📝 便签本（底部第二个小本子）

和日记不一样：**便签不挂日期**，是随手记的东西。
攒想法、记账号、抄一句想记住的话，都往这儿扔。

- 点底部 **📝 便签** 打开
- 一列一列的便签卡片，**2 列排布**
- 点 **＋** 新建 → 直接进编辑，光标自动到位
- 点任意一张便签 → 打开看内容、接着写
- **6 种便签颜色**（黄 / 粉 / 蓝 / 绿 / 紫 / 橙）
- **📌 置顶**：置顶的永远排最前面
- **🗑 删除**（会先问一句）
- 空白便签不留：点了 ＋ 又反悔，不会留下空卡片
- 右划退出：编辑里退回列表，列表里收起来

便签用的是**固定的浅色**，不跟本子的主题色走 ——
因为真实世界的便签就是那几个颜色，而且不管本子换成什么色，便签都该一眼认出来。

### 💾 备份与导出（小本子面板最下面）
| 按钮 | 做什么 |
|---|---|
| **导出备份** | 打包成一个 `.zip`：待办 + 日记 + 照片 + 专注记录 + 便签 + 设置 |
| **导入备份** | 读回来，覆盖当前设备的数据（会先问你确认） |
| **导出这天 PDF** | 把这天排成 A4 PDF |
| **导出本月 PDF** | 整月一页一天，月底存一本 |

导出时会走 iOS 的**系统分享面板**，可以直接「存储到文件」。
PDF 走 `window.print()`，在打印预览里点分享 → 存储到文件。

---

## 🔴 最重要的一件事

> **定期点「导出备份」，把 zip 存到「文件」App 里。**

浏览器的数据存在这台设备的这个浏览器里，**清掉浏览器数据就全没了**，
而且电脑和手机是**两套独立数据、不互通**（浏览器安全模型，不是 bug）。

## 开发

```
npm start           本地预览（等于双击 start.bat）
npm test            跑全部测试
npm run icons       重新生成主屏幕图标
```

| 命令 | 做什么 |
|---|---|
| `node tools/test-focus.mjs` | 专注引擎单元测试（56 项，毫秒级边界） |
| `node tools/test-zip.mjs` | ZIP 打包解包单元测试（27 项） |
| `node tools/smoke.mjs` | 浏览器端到端测试（234 项，真的开 Chrome 点） |

改完代码先跑 `npm test` 再部署。
